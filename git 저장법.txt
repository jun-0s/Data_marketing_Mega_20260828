로컬 컴퓨터 git 세팅
1. Windows 자격 증명 세팅
>검색바 >자격 > 자격 증명 관리자 > Windows 자격증명 > 일반 자격 증명 목록 >git-hub 오른쪽 드롭다운 버튼(아래쪽 방향 화살표)> 제거(이미 내 컴퓨터에 타인의 자격증명)

2. git 소유주 정보 전역(global) 등록
>cmd >관리자 권한으로 실행>
맥 : 터미널 대기

3. 소유주 정보 등록
git config --list(혹시나 컴퓨터 git사용자 목록 조회)
>user.email = 다른 사람 이메일 X
>user.name = 다른 사람의 이름 X
user.name & user.email 없으면 등록만 하면 됨

4.본격적인 등록
> git config --global user.name "이름 "
> git config --global user.email "이메일"

5. 등록 확인
git config --list

6. 루트폴더 안에 git 세팅
>루트폴더로 이동!! (폴더 위치 확인, 주소 복사)
> cd 복붙
> git init (*최초 한번)
> 숨김파일보기 체크
> .git <- 파일이름
mac -> command + shift +.

> .git 폴더 : staging area
> 1. 어떤 파일을 대상으로 버전 관리? git add .  (저장은 여기서 부터)
git status (관리하고 있는 대상)

2. 만약 특정 파일을 버전 관리 대상으로 결정했다면, 어떤 이름으로 관리할것인가?
git commit -m "260828_01(이름설정)"

3. 최종적으로 관리의 대상으로 결정? (*최초 한번만)

확인법 : git remote -v 

4. git-hub로 관리하기로 결정한 데이터/파일 업로드 단계
git push origin master
